TASK 1: USER DIRECTORY

GOAL:

DATA SOURCE:
https://jsonplaceholder.typicode.com/users

REQUIREMENTS:

* Show a loading spinner while fetching data

* Show a friendly error message if the API fails

5. Layout & Styling:

  • Desktop: 3 columns
